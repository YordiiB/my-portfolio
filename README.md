# React 3D Portfolio

Minimal 3D portfolio built with React 18, Vite, Three.js (react-three-fiber) and Tailwind CSS. Includes interactive 3D canvases, sections for hero, about, tech, experience, works, feedbacks and contact (EmailJS).

## Features
- 3D components: Earth, Computers, Tech balls, Stars
- Responsive layout with Tailwind CSS
- Contact form using EmailJS
- Vite-powered dev server and build

## Quick start
Prerequisites: Node.js (16+), npm

```bash
npm install
npm run dev        # start dev server
npm run build      # production build
